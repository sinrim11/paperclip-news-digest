### 문제 1 — 텔레그램 반복 전송 (근본 원인 확정)
DB 증거: 두산알프하임 14일 연속 14회 발송, 안양씨엘포레자이 13회, 삼신(갭투자) 13회.
- **메인 트랙**: 신저가 재등장 로직이 "직전 발송 중간값 vs 최근 14일 최저가"를 매일 재비교.
  이미 알린 저가를 기억하지 않아, 저가 거래 1건이 window 내내 매일 재등장을 트리거.
- **갭투자 트랙**: 쿨다운 체크가 아예 없었음 → 같은 단지 무한 반복.
- **excluded 로그**: 메인/스트레치+/갭 트랙이 같은 단지를 중복 기록 → 로그 노이즈.

### 문제 2 — 정책·대출 정보 미갱신

- `config/region-regulation.json` (규제지역 테이블 — 추천 합법성 게이트): asOf 2026-07-08

### 문제 3 — 수집 활동 보고 부재
- 수집(06:00)·스윕(03:00)·매칭(08:45)·리서치(07:00) 결과가 **파일 로그에만 기록**.

## 4. 다음 개선 로드맵 (우선순위순)

1. **주간 자가 회고 자동화**: 일요일 저녁, 한 주간 발송 이력·수집 통계·정책 변경을 모아
   "이번 주 시스템이 한 일 + 개선 제안" 회고 리포트 발송 (weekly-deepdive에 통합 가능)
2. **추천 품질 피드백 루프**: 텔레그램으로 받은 추천에 사용자가 반응(관심/제외)을 남기면
   recommendation-rules 가중치에 반영하는 학습 루프
3. **재등장 신호 다양화**: 현재 신저가 단독 → 거래량 급증·신고가 회복·전세가율 급변도
   재등장 트리거로 추가 (각 신호별 1회 알림 원칙 유지)
4. **하방 플래그 확장**: 입주물량(부동산원)·미분양(국토부 통계누리) 공식 소스 확보 시
   downside.ts에 증분 추가 (기존 보류 항목)
5. **naver-property-scraper 프로젝트 정리**: 5월 이후 방치 — news-digest 파이프라인과 중복.
   폐기 또는 통합 결정 필요.
